# Privacy policy — A3EM Card Helper extension

This is the extension's part of the full policy for the A3EM Dashboard, its extension and its
card helper, published at https://config.a3em.com/privacy.html. Where they differ, that page is
current.

The A3EM Card Helper extension collects no data, and sends nothing anywhere.

**What it does.** It passes messages between the A3EM dashboard (https://config.a3em.com, or a copy
of it running on this computer) and the A3EM card helper, a program installed separately on the
same computer. Those messages describe the SD cards connected to the computer and the operations
the dashboard asks for — checking a card, formatting it, writing its configuration file.

**What it does not do.** It makes no network requests of its own. It keeps no record of what
passes through it. It has no analytics, no tracking, and no access to web pages other than the
dashboard. It cannot read browsing activity.

**The card helper.** The program the extension talks to has no network code: it works only with
the browser that starts it and the cards and disks on this computer. It keeps two small files in
the user's own settings folder: a key that signs its confirmations, and a record of the cards it
has prepared (their size, format, and test results), so that a later check can report them.

**Contact.** Questions about this policy: https://github.com/vu-a3em/a3em-dashboard/issues
