The card helper is installed

Reload the A3EM dashboard. It should now show the helper as connected.

To check the installation from Terminal:
"/Library/Application Support/A3EM/a3em-card-helper" doctor

To remove it:
sudo "/Library/Application Support/A3EM/a3em-card-helper" uninstall --system
"/Library/Application Support/A3EM/a3em-card-helper" uninstall
sudo rm -rf "/Library/Application Support/A3EM"
