A3EM Card Helper

The A3EM dashboard uses this helper to prepare SD cards for A3EM recorders: it checks that a card really holds what it claims, formats it with the exact layout the recorder firmware expects, verifies the result, and writes the deployment's configuration.

It installs one program, in /Library/Application Support/A3EM, and registers it with Chrome, Edge, Chromium, Brave, Vivaldi, Opera, and Arc. It runs only when the dashboard asks it to, and asks for your password before it writes to any card.

You also need the A3EM Card Helper browser extension.
